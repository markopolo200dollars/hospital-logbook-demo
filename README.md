# Hospital Visit Logbook Demo

This static, browser-only prototype uses `index.html`, `styles.css`, and `app.js`. The repository and any GitHub Pages site built from it are public.

## Open locally

Open this folder in VS Code. To preview it locally, open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site on pushes to `main`. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**. After the workflow finishes, use the Pages URL shown in the repository's Pages settings.

## Demo and privacy

This is a demo only: it has no backend or authentication. Sample entries are fictional, and entries added in the browser are stored in that browser's local storage. Because this repository and the hosted page are public, do not enter real patient information.
